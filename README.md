# Minimum Time Search of a Lost Target Using Multimodal Particle Swarm Optimization with Multiple Unmanned Aerial Vehicles

This repository presents the following article in MATLAB:

Thu Hang Khuat, Hai Trung Le, Manh Duong Phung,  "**Minimum Time Search of a Lost Target Using Multimodal Particle Swarm Optimization with Multiple Unmanned Aerial Vehicles**", PrePrint, 2026

## Installation
```
git@github.com:thuhangkhuat/EMPSO_target_search.git
```

## Run simulation
The current version have six different scenarios. Before run each method, please change the value of `model` in file. To run our method:
1. Download all the source files from this repository.
2. Open MATLAB.
3. Execute the main script by running `EMPSO.m`.
